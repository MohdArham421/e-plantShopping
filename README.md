🌿 e-plantShopping
A modern React + Redux Toolkit based e-commerce web application for buying plants online. This project demonstrates global state management using Redux, component-based UI design, and GitHub Pages deployment.


🚀 Live Demo
👉 https://MohdArham421.github.io/e-plantShopping/


🛠️ Tech Stack
⚛️ React.js
🧠 Redux Toolkit
🎯 React-Redux
⚡ Vite
🎨 HTML5 + CSS3
💻 JavaScript (ES6+)


📦 Features
🌱 Browse different plants
🛒 Add plants to cart
➕ Increase / decrease quantity
🧮 Cart total calculation
🗑️ Remove items from cart
🌍 Global state management using Redux Toolkit
📱 Responsive UI
🚀 Deployed using GitHub Pages
🧠 State Management (Redux)



This project uses Redux Toolkit:
CartSlice.jsx → Handles cart actions (add, remove, update quantity)
store.js → Configures global Redux store
Provider → Makes store available to entire app



Installation & Setup
1. Clone the repository
git clone https://github.com/MohdArham421/e-plantShopping.git
2. Install dependencies
npm install
3. Run the project
npm run dev


🚀 Deployment (GitHub Pages)
Branch used: gh-pages
Build is automatically deployed to GitHub Pages
After push, wait 1–2 minutes for updates
